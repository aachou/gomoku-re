# 不一样的五子棋

这是一个支持“打子”规则的五子棋项目，包含桌面 UI 和终端模式。

## 目录结构
- `main.py`：程序入口，负责根据参数选择桌面 UI 或命令行模式。
- `game.py`：核心游戏规则、棋盘逻辑、AI 与 CLI 模式实现。
- `ui.py`：`tkinter` 桌面界面实现。

## 规则
- 先让自己连成 5 棋子的一方，不是直接获胜。
- 连线后回收这条 5 棋的棋子，并用自己的一颗棋子替换对方的一颗棋子。
- 如果替换后再次出现 5 棋连线，则继续重复该过程。
- 否则轮到对方落子。
- 先把棋子下完的一方判输。

## 玩法
- 运行 `python main.py`：默认启动桌面 UI（如果系统支持 `tkinter`）。
- 运行 `python main.py cli`：强制进入命令行模式。
- 支持人机对战，AI 有简单、中等、困难三种难度。
- 坐标格式支持 `A1` 或 `1 1`。

## 运行环境
- Python 3.8+
- 若需要桌面界面，请确保系统已安装并启用 `tkinter`。

## 示例
```bash
python main.py
```

## 开发说明
如果你想快速定位功能：
- 修改游戏规则、AI 逻辑请在 `game.py` 中进行；
- 修改界面样式、按钮和布局请在 `ui.py` 中进行；
- `main.py` 仅负责启动方式选择。
