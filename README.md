# 不一样的五子棋

> 经典五子棋的变体规则 —— 连成五子不会立即获胜，而是回收棋子并替换对方棋子，**先把棋子下完的一方判负**。

![Python](https://img.shields.io/badge/python-3.8+-blue) ![License](https://img.shields.io/badge/license-MIT-green)

## 快速开始

```bash
uv run main.py                 # 启动图形界面
uv run main.py cli             # 强制命令行模式
```

> `uv run main.py` 自动管理虚拟环境，无需手动安装依赖或激活虚拟环境。

## 游戏规则

1. **落子**：双方轮流在棋盘空格上放置自己的棋子。
2. **回收**：当一方在棋盘上连成 **5 颗或以上** 棋子时，不获胜，而是——**回收这 5+ 颗棋子**（从棋盘上移除），并加回自己的棋子库存。
3. **替换**：回收完成后，如果自己还有棋子库存且对方还有棋子，则必须**选择对方的一颗棋子替换成自己的**。
4. **连锁**：替换可能导致再次出现五子连线，继续回收→替换→回收…直到没有连线或无法替换为止。
5. **胜负**：**棋子库存先耗尽的一方判负**（对方获胜）。棋盘下满且双方都有库存时为平局。

### 举个例子

```
黑棋 ●●●●●    ← 连成五子
          ↓
五子回收，黑棋库存 +5
          ↓
黑棋替换一颗白棋为己用
          ↓
替换后可能再次形成五子 → 重复回收
```

## 功能特色

### 图形界面（GUI）

- **三种 AI 难度**：简单 / 中等 / 困难
- **人机对战 & 双人对战 & AI 观战**
- **悔棋**（Ctrl+Z）
- **步数历史**：侧边栏实时记录每一步落子和替换
- **双方计时器**：累计思考时间一目了然
- **调速滑块**：AI 思考延迟可调（适合慢节奏观战）
- **三套主题**：默认、森林、暖阳（主菜单实时预览）
- **键盘快捷键**：按 `?` 查看全部热键
- **存档/读档**（Ctrl+S / Ctrl+L），关闭窗口自动存档
- **对局统计**：跨 session 持久化记录胜/负/平/步数
- **棋盘坐标**、落子闪烁动画、窗口可缩放（默认 1200×800）
- **星位标记**：≥15×15 棋盘自动绘制标准五子棋星位/天元
- **落子预览**：鼠标悬停空位时显示半透明 ghost stone 预览
- **逐手回放**：对局结束后可 step-by-step 回放每一步，支持自动播放

### 命令行界面（CLI）

- 纯终端运行，无需图形依赖
- 支持 `undo` / `save` / `load` / `quit` 命令
- AI 思考过程有"思考中…"提示
- 坐标支持 `A1` 或 `1 1` 两种格式

## 性能参考

| AI 难度 | 平均每步耗时 | 搜索深度 |
|---------|------------|---------|
| 简单    | < 1ms     | 随机+中心偏好 |
| 中等    | ~1ms      | 1-ply |
| 困难    | ~35ms     | **2-ply α-β剪枝** |

*15×15 棋盘，约 20 枚棋子时测量。hard 模式使用 alpha-beta 剪枝搜索对手的最佳应对。*
